
# PINKOK 개발 규칙

- 모든 답변은 한국어로 작성한다.
- React Native + TypeScript 기반 프로젝트다.
- 백엔드는 Java/Spring Boot이며 AWS에 배포되어 있다.
- API_BASE_URL은 환경변수 설정을 따른다.

## 작업 원칙
1. 관련 파일과 기존 로직부터 확인한다.
2. 기존 UI, 기능, API 호환성을 유지한다.
3. 요구사항과 직접 관련 없는 코드는 수정하지 않는다.
4. 중복 구현 및 불필요한 라이브러리 설치를 피한다.
5. 프론트엔드 UI 수정은 Android 실기기 테스트를 고려한다.
6. 환경변수, API 키, Firebase 설정을 노출하지 않는다.
7. 기존 Git 변경사항을 보호하고 임의로 초기화하지 않는다.

## 토큰 최적화
- 프로젝트 전체가 아닌 관련 파일부터 검색한다.
- 이미 확인한 파일은 변경되지 않았다면 재분석하지 않는다.
- 전체 코드를 답변에 출력하지 않는다.
- 작업 완료 후 변경 파일, 핵심 수정, 검사 결과만 보고한다.
- 테스트를 실행하지 못했다면 검증하지 않았다고 명시한다.
- 여러 기능은 의존성이 있는 작업끼리 묶어 단계별로 구현한다.
